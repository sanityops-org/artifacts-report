# prompt-skill-tool — Agent Artifact Bundle Collection

This folder contains **17 complete agent artifact documents** copied from the internal `prompt-tool-skill` batch. Each document ships all three artifact layers in one file:

- a System Prompt;
- one or more Skill definitions; and
- one or more Tool Schemas.

These documents are unnumbered agent artifact bundles. They are intentionally **not** included in the 205 TC-numbered cases or in the combination counts in `../README.md`.

- All filenames and document content are in English.

- Embedded JSON blocks are kept parseable; they are not transformed into a separate runtime format.

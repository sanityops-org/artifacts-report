# prompt-tool — EMPTY (0 cases)

No case in the corpus currently ships both a loadable System Prompt **and** a loadable Tool Schema. This folder is the **most likely to become non-empty**; see "Pending" below.

## Why this folder is empty

Production agents define tools in code and convert them to schema at runtime, so the same product rarely ships a schema document alongside its prompt:

- Python: `CoreTool.from_function(...)`, `@tool` decorators, `BaseTool` subclasses — schema generated by `inspect.signature`.
- Go: MCP `mcp.Tool{InputSchema: ...}` built from `jsonschema` struct tags.
- PHP: `ShapeDescriptor` task shapes, not tool parameter schemas.
- TypeScript: Zod/TypeBox schemas defined inline in the tool factory.

The 49 `tool-only` cases are MCP servers — they ship schema but no prompt. The 67 `prompt-only` cases ship prompt but no schema.
